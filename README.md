# PowerRename (Rust)

一个类似 Windows PowerToys **PowerRename** 的批量重命名工具，使用 **Rust + egui** 实现，单文件可执行、零运行时依赖、跨平台（Windows / macOS / Linux）。

- **体积小**：release 单 exe 约 **2.9 MB**
- **速度快**：原生编译，启动即时
- **所见即所得**：输入规则实时预览，冲突/错误即时标红

## 功能特性

- **规则流水线**：规则按顺序依次应用，上一条输出是下一条输入；支持添加/删除/上移/下移/清空
- **规则类型**
  | 类型 | 说明 |
  |---|---|
  | 查找替换 | 支持忽略大小写，可指定作用范围（完整文件名 / 仅主名 / 仅扩展名） |
  | 正则替换 | 兼容 lookaround 等高级语法（fancy-regex），支持捕获组 `$1` |
  | 大小写转换 | 全部小写 / 全部大写 / Title Case / 仅首字符大写 |
  | 添加前缀 | 在文件名最前面插入文本 |
  | 添加后缀 | 在主名之后、扩展名之前插入文本 |
  | 序列编号 | 起始值、步长、位数补零、前缀或后缀插入、自定义分隔符 |
  | 替换扩展名 | 一键批量改扩展名（留空 = 去掉扩展名） |
  | 移除字符 | 逐个移除指定字符（如 `-()`） |
  | 压缩空白 | 合并连续空白；可选转下划线 |
  | 按清单重命名 | 导入 `原名→新名` 清单（txt/csv），按映射逐项改名；未匹配项保持原名 |
- **清单导入导出**：一键导出当前列表为 `原名 → 新名` 清单（无规则时为模板，回填后可再导入），与「导入清单」形成闭环
- **树形预览**：预览以目录树呈现，子目录可折叠展开；目录结构一目了然
- **实时预览**：输入规则即时刷新，状态着色区分 就绪 / 冲突 / 无变化 / 错误 / 跳过，附说明
- **冲突与安全检查**：目标重名、目标已在磁盘存在、非法字符（`<>:"/\|?*`）、空结果
- **两阶段重命名**：先全部改临时名再改目标名，支持 `a↔b` 互换和链式改名，出错自动回滚
- **撤销**：内存栈记录每次应用，一键恢复
- **目录筛选**：包含/排除关键词（支持正则）、递归子目录、包含文件/文件夹
- 右键预览行可「打开所在文件夹」定位文件（目录节点可「打开文件夹」）

## 构建与运行

要求：Rust 1.75+（edition 2021）。

```bash
# 调试运行（可选传目录路径，启动后直接加载）
cargo run -- <目录路径>

# 发布构建（单文件，体积优化）
cd rust
cargo build --release
./target/release/power_rename.exe          # Windows
./target/release/power_rename              # macOS / Linux
```

> 直接双击 exe 即可运行，目标机器无需安装任何运行时。

## 使用步骤

1. 输入或点击「浏览…」选择目标文件夹，点击「加载」；可勾选递归子目录/包含文件/包含文件夹，并用「名称包含/排除」过滤列表
2. 点击「+ 添加规则」选择规则类型，在下方面板填写参数；规则列表中可点选、删除、上移/下移、清空
3. **按清单重命名**：点击「导入清单…」，选择 txt/csv 文件，每行一条 `原名 → 新名`；支持分隔符 `→` / `->` / `=>` / Tab / 逗号 / 分号 / 竖线 / 连续空格，自动识别 UTF-8 / GBK 编码；导入后自动添加一条「按清单重命名」规则
4. **导出文件清单**：点击「导出清单…」→ 无规则时导出 `原名 → ` 模板，有规则时导出含新名的清单；可回填新名后再「导入清单…」形成闭环
5. 右侧预览实时显示每个文件的原名 → 新名与状态；状态着色：绿=就绪、红=冲突/错误、灰=无变化、浅灰=跳过
6. 确认无误后点击「应用」，如需恢复点击「撤销」

## 目录结构

```
rust/
├── Cargo.toml            # 依赖与 release 优化配置
├── src/
│   ├── main.rs           # 程序入口 + egui GUI
│   ├── lib.rs            # 库入口
│   ├── rules.rs          # 规则定义（10 类规则枚举）
│   ├── transform.rs      # 名称转换流水线（规则依次应用）
│   ├── fs_tree.rs        # 目录树加载与展平
│   ├── preview.rs        # 预览计算：转换 + 冲突检测 + 状态标注
│   ├── apply.rs          # 两阶段重命名执行 + 撤销
│   └── list_io.rs        # 清单文件读写（UTF-8 BOM / GBK 自动识别）
└── tests/                # 引擎测试
```

## 技术栈与设计

- **egui / eframe 0.31**：即时模式 GUI，纯 Rust、无系统依赖；`default-features=false` 关闭内置字体以压缩体积，界面字体运行时从系统加载（Windows 微软雅黑 / macOS 苹方 / Linux Noto CJK，逐级回退）
- **fancy-regex**：正则替换兼容 lookaround / 反向引用等高级语法
- **规则是线性流水线**：每个文件名按规则顺序依次变换，第 N 条输出是第 N+1 条输入（与 PowerRename 的多模式同时应用不同，更直观可预测）
- **冲突检测在预览阶段完成**：目标重名、目标被磁盘其他文件占用（不在本次列表内）、非法字符、空结果都会标红并跳过
- **两阶段执行**保证 `a→b, b→a` 互换与链式改名安全：阶段一全部改名到临时名（同目录 + UUID 后缀），阶段二再改到目标名

## 构建体积优化

| 手段 | 效果 |
|---|---|
| `opt-level = "z"` + `strip = "symbols"` | 省 ~6% |
| `lto = true` + `codegen-units = 1` + `panic = "abort"` | 省代码量 |
| 关闭 eframe `default_fonts`（内置 4 字体 ~1.4MB 不入包） | 省 ~33% |

最终 release 约 **2.9 MB** 单文件。

## 已知限制

- 撤销栈仅保存在内存中，程序退出后无法恢复
- 仅支持同一目录内改名，不处理超长路径 / 跨卷移动
- 界面依赖系统安装的中文字体；若系统无中文字体（极少数精简系统）会回退英文字体显示
